Your agent keeps its state in markdown files.

MEMORY.md, TODO.md, USER.md, SOUL.md. They grow every session, nobody prunes them, and one wrong line steers every run after it.

GhostPaw is seven small Node.js libraries that file that state as records you can read and delete. Most of them are a few SQLite tables inside your agent's own process.

Find the file you outgrew Read all seven on GitHub

Free, MIT licence, Node.js 24 or newer. All seven have zero runtime dependencies. No account and no service to run.

Where a markdown file stops working

  1. The junk drawer

    MEMORY.md grows every session and nobody prunes it. Developers say they pay tokens on every turn to reread lines that stopped being true.

    Instead: codex flags stale, fading and low-trust beliefs when you read them and recalls only active ones. Pruning becomes a list you can work through.

  2. The wrong fact

    One agent saves a wrong fact, and every other agent trusts it.

    Instead: In codex every belief records where it came from and how certain it is. A correction supersedes the old belief and keeps the lineage, so you can see what changed.

  3. Said it was done

    The agent reports the task finished. It is not.

    Instead: questlog will not finish a quest without a written outcome, and a blocked quest stays blocked until the one before it succeeds. An outcome is text, not a test, but it gives you something to check.

If memory makes you nervous

Plenty of developers switch agent memory off, because unread memories pile up and old lines win arguments. That is a fair worry. This is what GhostPaw does about it.

  • The database is a SQLite file your own process opens. You can read and delete every row with sqlite3.
  • A belief nobody confirms for 90 days is flagged stale.
  • Forgetting is one call: forgetBelief, or retire_belief to hard-delete.
  • Recall calls no model. It is full-text search plus local similarity over the active beliefs.
  • Each package is an import, not a framework. Take one and ignore the rest.
