GhostPaw

Durable, local, inspectable state for AI agents: memory, tasks, contacts, identity and procedures as zero-dependency SQLite libraries for Node 24+.

  • codex: belief and memory engine
  • questlog: tasks and calendar
  • affinity: social CRM core
  • souls: agent identity and prompt evolution
  • grimoire: procedural knowledge
  • email: IMAP/SMTP engine
  • telegram: Telegram bot engine
  • website: site engine
